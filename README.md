# hsk-3.0-vocab-companion
A companion tool for learning the new HSK 3.0 vocabulary, with built-in spaced repetition review modes.

Vocab is organised alphabetically and by levels. Each word can be marked as 'New', 'Learning' or 'Known'. Hanzi to meaning, meaning to Hanzi and mixed modes can be chosen for the spaced repetition review. When a word is marked as 'Learning' it is added to that level's deck. Each day, 10 words will be due. When reviewing a word, it can be graded as 'Again', 'Hard', 'Good' or 'Easy'. The spaced repetition intervals will then change according to the selected grade. Once a card reaches an interval of 21 days or more, it will be promoted to Known.
